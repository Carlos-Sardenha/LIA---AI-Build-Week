# Princípios (core beliefs)

1. **O dado é da pessoa.** Nada é compartilhado sem consentimento explícito, e o consentimento pode ser retirado. Mesmo modelo do open finance.
2. **Toda informação tem fonte.** Número sem link para o laudo, a foto ou a leitura não aparece na tela nem na resposta da IA.
3. **O original nunca muda.** A extração gera nota nova; o arquivo bruto fica intacto para conferência.
4. **A IA orienta, não diagnostica.** Alerta diz "vale procurar um médico", nunca "você tem X".
5. **Dado real não entra no repositório.** Repo público: só dado sintético em `data/sintetico/`. Os próprios dados de quem testa ficam fora do git.
6. **Demo primeiro.** Até 14/11, o que não aparece na live demo de 10 minutos espera.
