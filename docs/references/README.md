# Referências

Docs que os agentes podem ler. Biblioteca nova → salve aqui a doc em formato texto (ex.: `<lib>-llms.txt`).

## Desafio

- **ChatGPT Health** (EUA, jan/2026): conecta prontuários e o Apple Health às respostas do ChatGPT (OpenAI).
- **Estônia** (desde 2008): todo prestador envia os dados a um sistema nacional e o cidadão consulta os próprios registros (e-Estonia).
- **Apple Watch:** avisos de fibrilação atrial (2018), apneia do sono (2024) e hipertensão (2025) (FDA).
- **Parkinson:** dados de sensor de pulso identificaram, até sete anos antes, quem receberia o diagnóstico (Nature Medicine).
